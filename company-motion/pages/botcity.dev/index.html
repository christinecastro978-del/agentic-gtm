Suggestion

An idea for BotCity

"Automation or security?" is a positioning decision. A possible next step is to answer it with one category built around Shadow Python, then measure that category against the ARR target. Here is how I would approach that:

  • Turn the category ambiguity into a single position for Sentinel, and teach buyers to use the name Shadow Python.
  • Build product marketing for the governance, security and audit teams Sentinel already speaks to.
  • Work the funnel backward from the ARR target, so sales and marketing argue about the same numbers.

This is a proposal, not a description of BotCity's current marketing.
